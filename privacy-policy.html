1. 수집하는 개인정보 항목

Mwohaji 서비스는 별도의 회원가입 절차 없이 이용이 가능하며, 필수적인 개인정보를 요구하지 않습니다. 다만, 서비스 이용 과정에서 다음과 같은 정보가 자동으로 생성되어 수집될 수 있습니다:

  • 할 일 내용: 사용자가 입력한 할 일 텍스트
  • 카테고리 정보: 할 일을 분류하기 위한 카테고리명
  • 일정 정보: 시작/마감 시간 및 알림 설정
  • 반복 설정: 반복 일정 관련 설정 정보
  • 기기 및 브라우저 정보: 유형, 버전, 화면 해상도
  • IP 주소: 서비스 접속 시 자동 수집
  • 방문 일시, 서비스 이용 기록: 사용 패턴 분석용

Mwohaji 서비스에서 수집된 정보는 다음 목적으로만 활용됩니다:

  • 할 일 목록 관리 및 저장

3. 쿠키 및 로컬 스토리지 사용에 관한 사항

Mwohaji는 기본적으로 모든 개인정보를 사용자의 브라우저 내부(localStorage)에만 저장합니다.

할 일 기능 사용 시 설정한 정보(내용, 카테고리, 일정, 반복 설정 등)는 로컬 스토리지에 저장되어 브라우저를 닫았다가 다시 열어도 설정이 유지됩니다. 이러한 정보는 기기 내에 저장되며 외부로 전송되지 않습니다.

또한 사용자가 설정한 알림 정보(시간, 제목, 반복 여부 등)도 로컬 스토리지에 저장되어 다음 방문 시에도 설정이 유지됩니다.

4. 개인정보의 제3자 제공

제한적 제공: Mwohaji는 기본적으로 사용자의 개인정보를 외부에 제공하지 않습니다.

다만, 다음의 경우는 예외로 합니다:

  • Google Drive 백업 기능 사용 시: 사용자가 직접 선택하여 구글 드라이브에 백업 파일을 저장하는 경우
  • AI 채팅 기능 사용 시: Gemini API를 통해 구글 서버로 할 일 생성 요청이 전송되는 경우
  • 이용자가 사전에 동의한 경우
  • 법령에 의해 요구되는 경우

이러한 기능들은 사용자가 직접 선택하여 사용하는 선택적 기능이며, 기본 할 일 관리 기능은 모든 데이터를 로컬에만 저장합니다.

5. 개인정보의 처리 및 보유 기간

Mwohaji 서비스 자체에서는 사용자의 개인정보를 보유하지 않습니다.

모든 할 일 데이터는 사용자의 브라우저 로컬 스토리지에만 저장되며, 서비스 제공자(Mwohaji)는 이 정보에 접근할 수 없습니다.

로컬 스토리지에 저장된 할 일 정보와 설정 정보는 사용자가 브라우저의 캐시 및 데이터를 삭제하거나 각 기능의 초기화 옵션을 통해 직접 삭제하면 제거됩니다.

Google Drive 백업 기능을 사용한 경우, 백업 파일은 구글의 개인정보처리방침에 따라 관리됩니다.

6. Google 서비스 연동 시 개인정보 처리

Google Drive 백업 및 AI 채팅 기능 사용 시 구글 서버로 데이터가 전송될 수 있습니다.

6.1 Google Drive 백업 기능

  • 사용자 선택: 이 기능은 사용자가 직접 선택하여 사용하는 선택적 기능입니다
  • 데이터 전송: 백업 파일(.txt)이 구글 드라이브에 저장됩니다
  • 구글 정책: 저장된 데이터는 구글의 개인정보처리방침에 따라 관리됩니다
  • 토큰 만료: 보안을 위해 1시간 후 자동 로그아웃됩니다

6.2 AI 채팅 기능 (Gemini API)

  • 사용자 선택: 이 기능은 사용자가 직접 선택하여 사용하는 선택적 기능입니다

  • 구글 정책: 전송된 데이터는 구글의 개인정보처리방침에 따라 관리됩니다
  • API 키 필요: 사용자가 직접 Gemini API 키를 설정해야 합니다

이러한 Google 서비스 기능들은 사용자가 직접 선택하여 사용하는 것이며, 기본 할 일 관리 기능은 모든 데이터를 로컬에만 저장합니다.

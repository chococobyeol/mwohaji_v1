뭐하지... 할 일 관리 앱 사용법 가이드

기본 사용법

할 일 추가하기

  • 텍스트 입력: 상단 입력창에 할 일 내용을 입력하세요
  • 카테고리 선택: 입력창 아래 카테고리 버튼을 클릭하여 분류하세요
  • 저장: Enter 키를 누르거나 추가 버튼을 클릭하세요

마크다운 지원

할 일 내용에 마크다운 문법을 사용할 수 있습니다:

텍스트 스타일링:
**굵게** 또는 __굵게__ - 굵게 표시
*기울임* 또는 _기울임_ - 기울임 표시
~~취소선~~ - 취소선 표시
`인라인 코드` - 인라인 코드 표시

제목:
# 제목 1
## 제목 2
### 제목 3

목록:
- 순서 없는 목록
- 두 번째 항목

1. 순서 있는 목록
2. 두 번째 항목

링크와 이미지:
[링크 텍스트](URL) - 링크
![이미지 설명](이미지URL) - 이미지
![이미지](URL){width=300 height=200} - 크기 지정 이미지

인용구:
> 인용구 내용

코드 블록:
```
코드 블록
여러 줄
```

구분선:
--- 또는 ***

줄바꿈:
줄 끝에 두 개의 공백 또는 Enter 키
특별 기능: 이미지 크기 지정은 ![alt](url){width=300 height=200} 형식으로 지원됩니다. GitHub Flavored Markdown(GFM)을 지원하여 표, 체크리스트 등도 사용 가능합니다.

할 일 관리

할 일 편집

  • 일정 설정: 할 일 옆 아이콘 클릭하여 시작/마감 시간 설정
  • 반복 설정: 할 일 옆 아이콘 클릭하여 반복 주기 설정
  • 삭제: 할 일 옆 아이콘 클릭하여 삭제

완료 처리

  • 체크박스: 할 일 앞의 클릭하여 완료 처리
  • 완료 표시: 완료된 할 일은 체크 표시로 변경

카테고리 관리

카테고리 생성/수정

  • 새 카테고리: 버튼을 클릭하여 카테고리 관리 모달을 열고 새 카테고리 추가
  • 이름 변경: 카테고리 옆 아이콘 클릭하여 수정
  • 순서 변경: 아이콘을 클릭하여 카테고리 순서 편집

카테고리 삭제

  • 삭제: 아이콘을 클릭하면 카테고리가 삭제됩니다

데이터 관리

데이터 백업/복원

  • 백업: 버튼 클릭하여 모든 할 일과 카테고리를 .txt 파일로 저장
  • 복원: 버튼 클릭하여 백업 파일을 선택하여 데이터 복원
  • 백업 파일은 기본 다운로드 경로에 저장됩니다

AI 채팅 (Beta)

AI 기능

  • 자연어 입력: 채팅창에 "오늘 3시에 회의 준비 알림 설정" 같은 자연어로 할 일 생성
  • 카테고리 관리: "새 카테고리 만들기: 건강관리" 같은 명령으로 카테고리 생성
  • 일정 설정: "업무 카테고리에 보고서 작성 추가" 같은 요청으로 할 일 추가
  • 메시지 전송: 버튼 클릭하거나 Enter 키로 메시지 전송
주의: AI 기능을 사용하려면 Google Gemini API 키가 필요합니다.

Google Drive 백업 (Beta)

클라우드 백업

  • 구글 계정 로그인: 구글 계정으로 로그인하여 본인의 구글 드라이브에 접근
  • 동기화: 구글 드라이브에 저장된 내용과 현재 브라우저의 내용을 동기화
  • 토큰 만료: 구글 정책상 1시간 후 자동 로그아웃 (보안 강화)
주의: 이 기능은 Beta 버전입니다.
